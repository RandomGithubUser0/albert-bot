# Albert Bot

Automates Albert.io adaptive skill assignments using Claude vision API and Playwright.

## Setup
1. Clone the repo
2. `pip install -r requirements.txt`
3. `playwright install chromium`
4. Copy `.env.example` to `.env` and fill in your credentials

## Usage
`python main.py`
